# Существительные из OpenCorpora

Данные из корпуса были получены в промежутке 2016–2020 гг.
Изменения вносились, чтобы сделать словарь *более нормативным.*

В чистом виде корпус для тестирования библиотеки едва применим,
т.к. корпус по определению должен включать в себя всё, что употребляется.
Библиотека же должна всё-таки выдавать более-менее обычный текст.

**Словарь сжат.** См. `COMPRESSION.txt` за подробностями.
Запускайте `annotate.rb` чтобы получить словарь в виде простого текста.
Аннотированные файлы *построчно* соответствуют сжатым.
