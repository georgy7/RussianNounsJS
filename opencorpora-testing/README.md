# Существительные из OpenCorpora

Данные из корпуса были получены в промежутке 2016–2020 гг.<br>
Изменения вносились, чтобы сделать словарь *более нормативным.*

В чистом виде корпус для тестирования библиотеки едва применим,
т.к. корпус по определению должен включать в себя всё, что употребляется.
Библиотека же должна выдавать более-менее обычный текст.

**Словарь сжат.** Формат описан в `COMPRESSION.txt`.<br>
Скрипт `annotate.rb` создаёт копии json-файлов с построчными комментариями.
